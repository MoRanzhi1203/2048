## 2 关键更正（按严重度）

### P0

1. **第 2 篇“原子写”名不副实**：原文代码是 `open(..., 'w') + json.dump`，却声称原子写与损坏回滚。现替换为 V2 实际实现：`safe_store.atomic_write_json`、有效主文件才备份、`load_json_validated` + `.bak` 回退。
2. **第 2 篇 CSV 不是 append**：实际是“内存累积 + 整文件原子重写”；同时明确快照不含 RNG，不能声称逐位续玩。
3. **第 1 篇计分公式歧义**：明确“只计合并产生的新方块”，用 `[2,2,2,2] → 8`、`[2,0,2,4] → 4`、`[2,4,8,16] → 0` 三行实证。
4. **第 1 篇终止条件索引错误**：拆成水平 `j=1..3`、垂直 `i=1..3`。
5. **第 4 篇 60FPS 过度承诺**：16ms 只是目标 tick，`t += interval` 在丢 tick 时漂移，未测实际 FPS。
6. **第 4 篇“脏矩形”未实现**：实际是 `BoardView.update()` 整控件重绘；脏矩形列为未来方案。
7. **第 5b 篇 202 条测试缺少退出码**：本次逐套件复跑，95+28+5+5+41+17+11=202，全部 exit 0。
8. **第 6b 篇 500ms vs 1000ms**：以当前生产代码 `REPORT_INTERVAL_MS=500` 为准，1000ms 是已被取代的早期计划。

### P1（代表性）

- 第 2 篇：跨文件非事务、活档需状态文件、最大分取 `max`、微秒时间戳不是 UUID。
- 第 3 篇：快照不含 RNG；V3 DPI 三档无证据；撤销不会降低最高分。
- 第 5a 篇：`14279` 次采样更新为本次 `20000` 次结果；`8.5e-14` 标注历史；reward 与 2048 终止语义修正。
- 第 5b 篇：提示层像素/ΔE/通道/耗时标记 HISTORICAL；脚本式与 unittest 区分。
- 第 6a 篇：动作一致率限定在固定棋盘集/种子/参数；基准表标注来源且本次未重跑。
- 第 6b 篇：`readline()` 不保证非阻塞；`persist_official` 是四次按文件原子写，不是跨文件事务；检查点重试耗尽会报错。
- 第 6c 篇：62188 是测试夹具；E2E 22/22 与 exit 0 已给出原始 JSON 路径。
