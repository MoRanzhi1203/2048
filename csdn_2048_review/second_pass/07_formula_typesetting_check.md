## 2 本轮排版修改

### 2.1 第 1 篇

| 位置 | 原问题 | 修改 |
| --- | --- | --- |
| 初始状态 | 两个等式挤在同一行，逗号后断行 | 改为 `aligned` 两行，等号对齐 |
| 游戏结束条件 | 三个独立 `$$` 块，视觉上像三段无关公式 | 合并为一个 `aligned` 块，三条条件对齐 |
| 小结五式 | `cases` 内多行未对齐，`\sum \text{合并值}` 口径模糊 | 改为 `\left\{\begin{aligned}...\end{aligned}\right.`，用 $M_t$ 表示合并值集合 |
| 计分公式 | 下标为中文长句 | 改为 $\sum_{v\in M_t} v$，并在符号表定义 $M_t$ |
| 方向归约 | `\_merge\_line` 裸露下划线 | 改为 `\texttt{merge\_line}` |
| 符号 | 只有零散说明 | 新增符号表：$S_t$、score、best_score、won、game_over、$E_t$、$M_t$、$P_1/P_2$ |

### 2.2 第 5 篇（上）

| 位置 | 原问题 | 修改 |
| --- | --- | --- |
| 单调性 | 递增/递减两个求和挤在一行 | 拆为 `aligned` 两行 |
| 角落特征 | `\arg\max\in...` 语义不完整 | 先定义 $(i^*,j^*)=\arg\max_{i,j}s_{ij}$，再写 `cases` |
| Expectimax 机会节点 | 单行过长，CSDN 易横向溢出 | 拆为三行 `aligned`，保留 0.9/0.1 两项 |
| MCTS 根不变量 | 四项等式一行过长 | 拆为两行 `aligned` |
| 策略梯度 | 期望项与熵项一行过长 | 拆为两行 `aligned` |
| 损失函数 | 损失与 advantage 挤在一行 | 拆为两行 `aligned` |

### 2.3 第 5 篇（下）

| 位置 | 原问题 | 修改 |
| --- | --- | --- |
| 任务身份 | `id_{job}`、`id_{cur}` 直接斜体下标，易与变量混淆 | 统一为 `\text{id}_{\text{job}}`、`\text{id}_{\text{cur}}` |
| 快照签名 | `\big(...\big)` 与下标结合不够稳 | 改为 `\left(...\right)_{1\le i,j\le4}` |
| 接纳条件 | `running`、`id(r)`、`s_{cur}` 风格不统一 | 统一为 `\text{running}`、`\text{id}(r)`、`s_{\text{cur}}` |
| 符号 | 只有文字解释 | 新增符号表：id、$s$、$\sigma(s)$、$R$、$F$ |
| 着色域 | `R_{out}` 下标为斜体单词 | 改为 `R_{\text{out}}`，并用标准 `\setminus\bigcup` |

## 3 CSDN 兼容性检查

| 项 | 结构检查 | 风险 | 处理 |
| --- | --- | --- | --- |

| 公式内 HTML / 未转义 `%` | 0 处 | 低 | 未使用 |
