# 02 系列结构、标题、标签与导航（P3/P4）

## 1 系列定位

- **专栏名**：从零实现 2048：Python、PyQt5 与 AI 求解
- **专栏简介**：以 2048 为主线，从控制台数学模型一路实现到 PyQt5 桌面版、五类搜索算法、四类计算后端与无头后台求解。每篇保留可运行代码、失败案例与可复核的测试/基准证据，重点讲清“为什么这样做”和“边界在哪里”。
- **读者路径**：Python 基础 → GUI 与 MVC → 动画与渲染 → 搜索算法 → 并发与进程 → 工程一致性。
- **版本边界**：V1/V2 控制台，V3 MVC + 撤销重做，V4 动画与粒子，V5 求解与工作台，V6 计算后端 + 无头后台 + 跨模式交接。文章不把后续版本的能力倒灌到早期版本。
