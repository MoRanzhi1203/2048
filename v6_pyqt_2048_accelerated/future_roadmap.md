# V6 后续规划（本次**不**实现）

> 本清单仅为分期规划，V6 本轮**不**偷加以下功能；如后续实施须另行立项与验收。

## 1. 双人 / 人机 / 联网（原 V6 指令中提及，本轮明确不做）
- 本地双人（同一窗口轮流落子）与「人机竞技」。
- 联机对战：账号、匹配、网络协议、断线重连、服务端权威回放。
- 反作弊与赛季/排行榜。

## 2. 强化学习演进
- 自适应探索（按局面不确定性调节 ε / 温度）。
- 增量训练与更长训练预算下的 best/latest 双检查点策略评估。
- 现有 V5 推理热缓存基础上，做经 profiling 证明的剩余热点优化。
- **不**在本轮引入 DQN 经验回放或替换正式模型（会改变算法范式）。

## 3. 计算后端与搜索
- MCTS/Expectimax 的**原生整树搜索**（树节点驻留 C++/Numba，减少 Python 往返），
  使位棋盘后端在搜索密集算法上获得更大收益。
- Numba/C++ 的批量 rollout 作为搜索加速器（当前仅提供与验证内核，未接入算法主循环）。
- 增量/持久化转置表、开局面谱（book）。

## 4. 持久化与工程
- 求解历史从原子 JSON 升级为增量持久化或轻量数据库（本轮保持 V5 已验证的 JSON + `.bak`）。
- 多后端进一步微基准纳入 CI 门禁（回归阈值告警）。

## 5. 视觉与无障碍
- 高 DPI（125%/150%）真实视觉验收（本轮 `DPI_VISUAL=UNVERIFIED`）。
- 键盘/快捷键帮助面板、色盲友好配色方案（需产品确认）。
