# 2048 第六版（V6）· 功能说明

V6 是**计算后端 / 性能体系**的主体版本：在独立目录 `v6_pyqt_2048_accelerated/` 中，
以第五版（V5.1）已通过验证的算法与界面为基线，接入 **Reference / NumPy / Numba / C++ Bitboard**
四类计算后端、统一 API、严格等价测试、公平性能基准，并保持 GUI 兼容与数据隔离。

> 本版本**不改** 2048 原始规则、不改五策略定义、不改奖励/权重/随机分布；V1–V5 源码与正式模型只读。

## 2. 四类计算后端

| 后端 | 内核 | 说明 |
| --- | --- | --- |
| `reference` | 冻结 V5 纯 Python | **所有等价的对照基准**，支持任意大数值 |
| `numpy` | 16-bit 行查表 + NumPy 向量化评估 | 4×4 单盘**不**强行多重向量化 |
| `numba` | `@njit(cache=True)` nopython | 滑动/合并/评估/续玩内层整体编译 |
| `cpp` | C++20 + pybind11 + 64-bit bitboard | 65536 行预计算表；批量接口 |

**溢出规则**：`cpp`/`numba` 以 4-bit 指数编码，最大可表示 32768；遇到 65536 及更大方块时
**显式抛 `BoardOverflowError`，并回退 reference 重算同一决策**，绝不静默截断或替换算法。

## 3. 统一 API

- `solver_v6.solve(grid, strategy='expectimax', backend='auto', **options)`：保持 V5 签名；
  `backend ∈ {auto, reference, numpy, numba, cpp}`。
- 结果在 V5 字段基础上新增 `backend_requested / backend_used / backend_fallback_reason /
  backend_metrics`（不破坏老界面与导出解析）。
- `build_config / describe_config / STRATEGIES / STRATEGY_ORDER / PRESET_*` 等与 V5 一致。

## 4. 五策略

`heuristic / rollout / expectimax / mcts / rl` 与 V5 完全一致：**算法只实现一份**，
由后端提供原语（move/legal/evaluate/empty/game_over/sample_spawn），因此“换后端”不改变算法。

- `rl` 只**读取**正式模型（V6 无自有模型则读 V5 的 `rl_model.npz`），绝不训练或替换。

## 5. GUI 与数据隔离

- 复用 V5.1 双栏界面：左游戏台 + 右「AI 求解」工作台、QSplitter、贴边半胶囊把手、
  完全折叠无残留；行为与 V5.1 一致。
- 隔离：`2048_HISTORY_DIR` 把 v3/v4/v5 继承链的存档目录全部重定向到 V6 的 `game_history/`；
  会话/导出指向 V6 的 `solver_results/`（沿用 V5 已验证的原子保存 + `.bak` 回退）。
- 后端选择位于「高级参数」折叠区内（默认不向普通用户暴露）；标题栏显示当前后端。

## 6. 运行

```powershell
# 启动 GUI（默认 backend=auto）
$env:PYTHONNOUSERSITE="1"
& E:\anaconda3\envs\2048\python.exe v6_pyqt_2048_accelerated\v6_pyqt_2048_accelerated.py

# 指定默认后端（也可在界面「高级参数」内切换）
$env:V6_BACKEND = "cpp"
```

## 7. 基准

```powershell
& python v6_pyqt_2048_accelerated\benchmarks\run_micro.py                 # 内核微基准
& python v6_pyqt_2048_accelerated\benchmarks\run_search.py                # 同工作量搜索对照
& python v6_pyqt_2048_accelerated\benchmarks\run_pilot.py --mode smoke     # 小样本对局(2 局/算法)
```
默认规模：Smoke 2 局、Pilot 5 局、Final-lite 10 局；**不**自动执行每配置 100/300 局。
