## 1. P0 根因（本轮入口状态的“不明显”）

本轮入口 = 上一轮“暖白边 + 内向流光”方案（A+B v1，未提交，参数见上一轮报告 `20261011_ai_hint_ab/HINT_AB_REPORT.md`：主色 `#FFF4E7`、过渡 `#F2DDC6`、`_EDGE_PEAK=0.80`、3 条约 3px 流光、alpha 约 0.32、30 FPS）。

以**真实 Qt 渲染**（同一棋盘、同一方向、多相位）分阈值量化后，问题是**对比被稀释**，而非被遮挡或坐标错位：

| 指标（目标边中段 / 内部留白流光） | 入口状态 A+B v1 | 本轮修复后 |
| --- | --- | --- |
| A 层 ΔL≥30 的**沿边**覆盖 | 约 44% | **73.7%** |
| B 层峰值 ΔL | 约 22（ΔL≥30 面积 = 0） | **约 59（ΔL≥30 面积 ≈124 px）** |

- 根因 1：A 层暖白被“0.13/0.87 起、中心仅 0.34×峰值”的宽渐变摊薄，峰值仅 0.80，导致整条边**平均明度提升不足**，静止图与棋盘底色区分度低。
- 根因 2：B 流光是“约 3px 细长白色擦痕 + alpha 0.32”，峰值 ΔL 仅约 22，且无任何像素达到 ΔL≥30 —— 按“有实际辨识度的明暗变化”标准等于**不可见**。
- 未发现剪裁路径错误、坐标偏移或图层覆盖缺陷（`_background` 裁剪 = 圆角外轮廓 ∖ 16 瓦片矩形，实测 `on_tile=0`、`outside_outer=0`）。

## 7. 绘制性能（Overlay paintEvent，独立 render，N=200/配置）

| DPR | 无提示 mean/p95 (ms) | A mean/p95 | A+B mean/p95 |
| --- | --- | --- | --- |
| 1.00 | 0.0171 / 0.0275 | 0.0905 / 0.1496 | **0.3676 / 0.5210** |
| 1.25（受控模拟） | 0.0330 / 0.0641 | 0.2571 / 0.4223 | **0.9028 / 1.6939** |
| 1.50（受控模拟） | 0.0594 / 0.0957 | 0.6938 / 1.4132 | **1.9701 / 3.0839** |

- 预算（目标）：A+B 平均 ≤2ms、P95 ≤5ms —— **三档 DPR 全部满足**（1.25 受控模拟由上一轮 2.082ms 降至 **0.903ms**，因 A 层改 QPixmap 缓存 + 流光由 3 条减为 2 条）。
- 单帧时钟 26 FPS；A 静态层缓存；动画仅脏矩形 `update()`；无提示/不可见时不运行动画时钟。

**A-only 降级证明**：`set_flow_enabled(False)` 时 `gap_flow=0`、`_timer.isActive()==False`（真正停表），且目标边 A 高亮仍存在；`set_flow_enabled(True)` 后 `_timer.isActive()==True`。

## 10. 全部未验证事项 / 独立问题

1. `GUI_VISUAL`：自动截图与像素/亮度测量**不等于**人工视觉通过；上述改进是否“足够明显”须由用户目视确认。
2. `DPI_VISUAL`：真实 Windows 125%/150% 未测；本报告 1.25/1.50 仅为 `QT_SCALE_FACTOR` **受控模拟**。
3. 独立问题（本轮**未改动**）：单步跟随模式下，求解在途时的用户合法按键会被 `on_move` 提前返回而忽略——属既有并发语义，非纯渲染问题。
4. 捕获进程偶发在解释器退出阶段返回 `0xC0000005`（Qt 退出期访问冲突），但**输出 JSON 与 PNG 均已完整写出**；对证据无影响（本轮已改为显式 `os._exit(0)` 规避）。
