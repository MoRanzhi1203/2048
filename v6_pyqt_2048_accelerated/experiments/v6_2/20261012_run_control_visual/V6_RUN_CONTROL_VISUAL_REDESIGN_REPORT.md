## 1. 设计目标与改动

在“统一控制模块”基础上做视觉再设计，去掉最后的深色块与视觉噪声，建立清晰层级：

| 元素 | 旧 | 新 |
| --- | --- | --- |
| 标题行 | 单行文字 `AI 运行控制` | 标题 + 右侧**状态徽标**（未运行/运行中/已暂停/已停止/已结束/出错） |
| 三档选择 | 深棕底 `#3a332d` + 金色选中 `#c9a227` | **浅米灰分段** `#f3ece1` + 暖棕选中 `#8f7a66`，等宽、28px 高 |
| 性能摘要 | 两行纯文本 | **浅米灰卡片** `#f7f1e7`、8px 圆角、7/10 内边距，键值更清晰 |
| 主按钮 | 30px、4px 圆角 | 32px、6px 圆角，暖棕 + hover/pressed/disabled 三态 |
| 停止按钮 | 30px、4px 圆角 | 32px、6px 圆角，米白描边幽灵按钮 |
| 间距 | 4–6px 混用 | 统一 8px 节奏（段内 6px） |

未新增面板/按钮，未引入高饱和色；仍为暖灰/米白/棕体系。
