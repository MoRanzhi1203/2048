# V6 公平基准规范（Phase 0-F 建立，后续阶段执行）

> 本文件只**建立约定与最小 smoke gate**。Phase 0 不执行、也不宣称任何 V6 性能收益；
> 所有加速结论必须留到 V3–V5 阶段以真实证据给出。

## 1. 两类基准必须分开报告，禁止混合排名

| 类别 | 目的 | 度量对象 | 报告文件 |
| --- | --- | --- | --- |
| **Backend Microbenchmark** | 比较可比内核的吞吐量与调用开销 | 单盘 `move` / `legal_moves` / `spawn` / 逐项 `evaluate` / rollout 步 | `benchmarks/reports/` 下独立条目 |
| **Solver End-to-End Benchmark** | 比较真实算法决策耗时、搜索效率与对局表现 | 每次决策耗时、节点数、达成分数、最大瓦片 | 独立条目，**不与 microbench 混合排名** |

> 禁止把「纯 Python Expectimax」与「C++ MCTS」比较后得出「C++ 内核加速」的结论。
> 后端对照必须**同一种策略、同一工作量语义**。

## 2. 固定实验条件（两条对照各自独立）

| 条件 | 要求 |
| --- | --- |
| 棋盘输入 | 完全相同的固定集合（`boards.jsonl`，sha256 校验） |
| 随机种子 | 固定并写入记录（`--seed`） |
| 算法规则 | 相同（复用冻结的 V5 `solver_2048` 定义，不另起一套） |
| 搜索预算 | **同一语义**：或固定工作量（节点/模拟/深度），或固定墙钟预算（二者不可混用） |
| 搜索深度 | 明确且一致 |
| 计时边界 | 初始化 / JIT 编译 / 扩展导入与运行循环**分离**；warm-up 与测量分离 |
| Numba JIT | 单独 warm-up，预热后另报首次编译成本与缓存命中 |
| C++ 扩展 | 单独初始化，另报构建/导入成本 |
| 线程数量 | 记录并控制（`OMP/MKL/NUMBA/NUMEXPR_NUM_THREADS`，当前均未设置 → 依赖默认） |
| 棋盘集合 | 固定、可复现、带 sha256 |
| 输出 | 结构化 JSON + CSV，写入带时间戳的独立目录，**绝不覆盖**旧结果 |

## 3. 两种对照设计（必须分别设计，不能互相替代）

1. **同算法 + 同搜索预算 → 后端效率对照**
   固定算法、评估函数、深度 / 完成节点数 / 模拟次数与公共随机事件流，
   比较 `节点/秒`、`动作一致率`、`评估值偏差`、`缓存命中`、`模拟回传不变量`。
2. **同墙钟预算 → 实际求解效果对照**
   仅对「等价性与微基准均已通过」的后端运行；同批种子/事件流、同 CPU 资源、交错运行顺序，
   记录平均/中位分、最大瓦片、自然结束 vs `TRUNCATED`、单步耗时、预算触发次数、异常动作。

> 相同运行时间 **不等于** 相同计算工作量；固定工作量 **不等于** 相同实际耗时。

## 4. 运行模式（沿用 V5.1 轻量预算，禁止旧版“每配置≥100 局”硬门禁）

| 模式 | 每算法/后端局数 | 每局最多步数 | 每步时间预算 | 用途 |
| --- | ---: | ---: | ---: | --- |
| `smoke` | 2 | 200 | 20 ms | 流程与字段验证、改动后快速回归 |
| `pilot`（默认） | 5 | 400 | 30 ms | 轻量端到端回归 |
| `final-lite` | 10 | 400 | 30 ms | 阶段性验收，**不作**显著性结论 |

400 步未自然结束记 `TRUNCATED`，自然结束记 `FINISHED`；单步预算触达记 `TIME_BUDGET_REACHED`，两者与 `ERROR` 严格区分。

## 5. 每次运行必须记录的元数据

机器环境、源修订（git HEAD/状态）、后端二进制 sha256、依赖与编译标志、`boards.jsonl` sha256、
种子 / 事件流、完整运行命令、原始 JSON/CSV、统计摘要（median / p95 / mean / std / n）。

## 6. Phase 0 已建立 / 尚未具备

- **已建立**：固定棋盘集合（`boards.jsonl` + `boards.sha256`，6 组 × 8 = 48 盘）、
  可运行的 reference 最小 smoke gate（`smoke_gate.py`）、本规范与 `baseline_manifest.json`。
- **尚未具备**（后续阶段实现，本次**不得**伪造）：NumPy / Numba / C++ 内核，
  Solver End-to-End 对局基准，消融矩阵，统计显著性与排名结论。
